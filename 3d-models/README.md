# 3D Models

Printable parts for the 10 inch server rack the homelab sits in, and the mounts for the kit inside it.

| Folder | Contents |
| --- | --- |
| [server-rack](/3d-models/server-rack/) | The rack itself: the top and bottom frames, and the parts for each 3U section |
| [accessories](/3d-models/accessories/) | Shelves, plates and mounts that fit inside the rack |

## Building a Rack

A rack is a bottom frame and a top frame, with one or more 3U sections stacked between them. A new rack needs the frame parts once, plus the 3U section parts for every section you want.

### Frame (once per rack)

| Part | Folder |
| --- | --- |
| [10 Inch - Bottom Frame Base.stl](/3d-models/server-rack/10%20Inch%20-%20Bottom%20Frame%20Base.stl) | server-rack |
| [10 Inch - Bottom Frame Connector.stl](/3d-models/server-rack/10%20Inch%20-%20Bottom%20Frame%20Connector.stl) | server-rack |
| [10 Inch - Top Frame Base.stl](/3d-models/server-rack/10%20Inch%20-%20Top%20Frame%20Base.stl) | server-rack |
| [10 Inch - Top Frame Connector.stl](/3d-models/server-rack/10%20Inch%20-%20Top%20Frame%20Connector.stl) | server-rack |

### 3U section (once per section, at least one per rack)

| Part | Quantity | Folder |
| --- | :---: | --- |
| [10 Inch - 3U Cage Nut Rail.stl](/3d-models/server-rack/10%20Inch%20-%203U%20Cage%20Nut%20Rail.stl) | 4 | server-rack |
| [10 Inch - Inside Connector.stl](/3d-models/server-rack/10%20Inch%20-%20Inside%20Connector.stl) | 4 | server-rack |
| [10 Inch - Outside Connector.stl](/3d-models/server-rack/10%20Inch%20-%20Outside%20Connector.stl) | 4 | server-rack |

For example, a 6U rack is the frame plus two 3U sections: 8 cage nut rails, 8 inside connectors and 8 outside connectors.

To make an existing rack taller, print just the 3U section parts for each section being added.
